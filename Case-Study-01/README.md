# Technical SEO Audit

## Project

A content website with declining organic traffic.

---

## Challenges

- Slow page speed
- Duplicate meta descriptions
- Missing schema
- Poor internal linking
- Crawl issues

---

## Audit Process

✔ Crawl using Screaming Frog

✔ Review Google Search Console

✔ Identify duplicate pages

✔ Analyse Core Web Vitals

✔ Review index coverage

---

## Recommendations

- Improve page speed
- Add schema markup
- Optimise title tags
- Improve internal links
- Fix indexing issues

---

## Results

- Improved crawl efficiency
- Better index coverage
- Higher organic visibility
- Improved user experience
